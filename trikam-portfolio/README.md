## ✨ Key Features

- 🎯 **Credible Project Showcase**: Detailed breakdowns of flagship systems (SkillSense AI, Game Hub, Cinephiles Watch) with live demos and architecture diagrams.
- ⚡ **High-Performance Architecture**: Zero bloated GIF assets, Vite chunk splitting, and sub-second load times.
- 📊 **GitHub Activity Telemetry**: Live multi-mirror statistics tracking commits, streaks, and top programming languages.
- 🎨 **Figma Prototypes**: Interactive UI wireframes and user flow previews.
- 📧 **Direct Contact Pipeline**: Form validation and real-time email dispatch via EmailJS.
- 📄 **Embedded Resume Viewer**: In-browser PDF preview with instant download capability.
- ♿ **Accessible & SEO Ready**: Semantic HTML5, ARIA labels, structured JSON-LD schema, and custom Open Graph assets.

## 🚀 Local Development

1. **Clone the repository**
   ```bash
   git clone https://github.com/TrikamDevasi/Portfolio.git
   cd Portfolio/trikam-portfolio
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Configure Environment Variables**
   Create a `.env.local` file with your EmailJS keys:
   ```env
   VITE_EMAILJS_SERVICE_ID=your_service_id
   VITE_EMAILJS_TEMPLATE_ID=your_template_id
   VITE_EMAILJS_PUBLIC_KEY=your_public_key
   ```

4. **Run development server**
   ```bash
   npm run dev
   ```

5. **Run test suite**
   ```bash
   npm test
   ```

6. **Build for production**
   ```bash
   npm run build
   ```
